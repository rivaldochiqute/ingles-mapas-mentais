# Inglês em Mapas Mentais · página de vendas

Página estática (HTML + imagens), sem build. Hospedada na Vercel.

## Antes de anunciar
1. Abra `index.html` e troque `CHECKOUT_URL` pelo link do checkout da Hotmart ou da Kiwify.
2. Cole o código do Meta Pixel no `<head>` (há um comentário a marcar o lugar).
3. Troque `contato@seudominio.com` e os links de Termos e Privacidade no rodapé.

Cada `git push` na branch `main` publica uma nova versão na Vercel.
